# 組合せ・順列・重複組合せ (素数 mod)

組合せ $nCr$、順列 $nPr$、重複組合せ $nHr$ を素数 mod 上で計算するライブラリです。

階乗および階乗の逆元を前計算することで、一度前計算した範囲内では各値を定数時間で取得できます。  
必要になった $n$ まで内部の前処理配列を自動で拡張するため、コンストラクタで上限を指定せずに利用できます。

このライブラリは、$n$ が比較的小さく、同じ範囲に対する問い合わせを多数処理したい場合に適しています。  
目安として、$n$ が $10^6$ 程度まで、またはメモリに余裕があれば $10^7$ 程度までの場合に向いています。

$n$ が $10^9, 10^{12}, 10^{18}$ など非常に大きく、$r$ が比較的小さい場合は、`large_combinatorics` を使用してください。

テンプレート引数 `mint` には、`atcoder::modint` 系の型を指定することを前提としています。

## コンストラクタ

### combinatorics()

```cpp
combinatorics()
```

空の `combinatorics` を作成します。  
前処理配列は、`C`、`P`、`H` が呼ばれたときに必要な範囲まで自動で拡張されます。

**計算量**
- $O(1)$

### combinatorics(int n)

```cpp
combinatorics(int n)
```

$0$ 以上 $n$ 以下の階乗および階乗の逆元を前計算します。

明示的に前計算範囲を確保したい場合に使用します。  
このコンストラクタを使わない場合でも、各関数の呼び出し時に必要な範囲まで自動で前計算されます。

**制約**
- $0 \leq n < \mathrm{mod}$

**計算量**
- $O(n)$

---

## operator()

```cpp
mint operator()(int n, int r)
```

組合せ $C(n, r)$ を素数 mod 上で返します。  
`C(n, r)` と同じ値を返します。

$n < 0$、$r < 0$、または $r > n$ の場合は `0` を返します。

**制約**
- $0 \leq n < \mathrm{mod}$

**計算量**
- $O(1)$
- ただし、これまでに処理した最大の $n$ を超える場合は、追加で前処理配列の拡張に $O(n)$

---

## C

```cpp
mint C(int n, int r)
```

組合せ $C(n, r)$ を素数 mod 上で返します。

$$
C(n, r) = \frac{n!}{r!(n-r)!}
$$

$n < 0$、$r < 0$、または $r > n$ の場合は `0` を返します。

**制約**
- $0 \leq n < \mathrm{mod}$

**計算量**
- $O(1)$
- ただし、これまでに処理した最大の $n$ を超える場合は、追加で前処理配列の拡張に $O(n)$

---

## P

```cpp
mint P(int n, int r)
```

順列 $P(n, r)$ を素数 mod 上で返します。

$$
P(n, r) = \frac{n!}{(n-r)!}
$$

$n < 0$、$r < 0$、または $r > n$ の場合は `0` を返します。

**制約**
- $0 \leq n < \mathrm{mod}$

**計算量**
- $O(1)$
- ただし、これまでに処理した最大の $n$ を超える場合は、追加で前処理配列の拡張に $O(n)$

## H

```cpp
mint H(int n, int r)
```

重複組合せ $H(n, r)$ を素数 mod 上で返します。

$$
H(n, r) = C(n + r - 1, r)
$$

$n$ 種類のものから重複を許して $r$ 個選ぶ場合の数を表します。

$n < 0$ または $r < 0$ の場合は `0` を返します。  
また、$n = 0$ の場合は、$r = 0$ のときのみ `1` を返し、それ以外では `0` を返します。

**制約**
- $0 \leq n$
- $0 \leq r$
- $n = 0$ または $n + r - 1 < \mathrm{mod}$

**計算量**
- $O(1)$
- ただし、これまでに処理した最大の $n + r - 1$ を超える場合は、追加で前処理配列の拡張に $O(n + r)$
